# School-Website-Final-Major-project-in-Html-Css-Javascript
A final project to commemorate my journey in learning how to make websites. 

I returned to studying HTML, CSS, and JavaScript in the summer of 2026 after taking a year off due to school, and I learnt a lot. To show my knowledge, I made a final project to commemorate my journey in learning how to code. This project solves the issue of my school not having an official website and how unorganized or how tedious the school website through BPS may be. This project combines original designing with the addition of during the development phase, I used Chat Gpt in this project like you would in the real world to help with debugging and tedious, repetitive tasks like making the website responsive and adding the header and footer to every page. But I maintained full responsibility for the designs, structure, and final implementation of this project. This last major project in Web Development marks the switch into my journey from web development to programing for robotics/embedded systems.
